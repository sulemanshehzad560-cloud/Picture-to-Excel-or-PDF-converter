# Third-party components

OmniScan bundles these open-source components. Their licences apply to them.

| Component | Use | Licence |
|---|---|---|
| PaddleOCR PP-OCRv6 detection and recognition models, PP-OCR text-direction classifier (via the RapidOCR 3.9.2 distribution) | On-device text detection and handwriting/print recognition | Apache-2.0 |
| ONNX Runtime Web | Runs the models (WebAssembly) | MIT |
| OpenCV.js (@techstark/opencv-js) | Page detection, image clean-up, table ruling detection | Apache-2.0 |
| ExcelJS | Excel export | MIT |
| docx | Word export | MIT |
| pdfmake (with Roboto font) | PDF export | MIT (Roboto: Apache-2.0) |
| PDF.js (pdfjs-dist) | Opening scanned PDFs | Apache-2.0 |
| JSZip | CSV bundles | MIT (or GPLv3) |
| Capacitor and plugins | Android app shell | MIT |
| Space Grotesk, JetBrains Mono (Fontsource) | Interface fonts | SIL OFL 1.1 |
| Tesseract, FastAPI, openpyxl, python-docx, ReportLab, Anthropic SDK | Optional Python server | Apache-2.0 / MIT / BSD |
